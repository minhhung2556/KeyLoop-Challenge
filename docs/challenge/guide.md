# Technical Coding Challenge Guide

Thank you for applying for the Engineering Lead role at Keyloop!

As the next step, we'd like you to complete a short technical coding challenge. Here's what to do:

1. Pick one out of four scenarios from the attached challenge document
2. Prepare a brief system design document
3. Implement either the backend or frontend service layer
4. Push your code to a Git repository (with documentation and tests)
5. Record a 5–10 minute video walkthrough of your solution

Once ready, please reply to this email with:
• A link to your GitHub repository
• A link to your video walkthrough

We'd kindly ask you to submit your solution within one week.

After reviewing your submission, we'll invite you to a technical interview to discuss your approach in more detail.
